Conclusion from the archived run:

but uses more generic mapped logic cells than the RCA.

Reproducibility status
----------------------
The synthesis script at synthesis/run_synthesis.ys has been aligned to
synthesize each complete ALU with flattening, run check, collect stat
and ltp -noff output, and save per-ALU logs. The archived values above
have not yet been regenerated from that updated script. Re-run the
script and compare reports/alu_rca_synthesis.log and
reports/alu_cla_synthesis.log before treating the table as reproduced.
Exact values may vary with Yosys/ABC versions.

Limitations
-----------
These results do not establish physical area, power consumption, or
propagation delay in nanoseconds. Those require a suitable target-cell
library, constraints, and appropriate technology-specific implementation
and timing analysis. Topological path length is a logic-depth metric,
not a clock period or a delay measurement.
